
# Day 2 - Phase Portrait

## Objective

Understand state space representation using angle and angular velocity.

## State Variables

- Theta (Angle)
- Omega (Angular Velocity)

These two variables completely describe the pendulum state.

## Graphs Generated

1. State Variables Plot
2. Real State Space Dynamics
3. Phase Portrait

## Observations

- The pendulum state evolves continuously over time.
- Angular velocity changes due to gravity.
- The phase portrait shows the trajectory of the system in state space.
- The angle grows continuously because the current model is unstable and unbounded.
